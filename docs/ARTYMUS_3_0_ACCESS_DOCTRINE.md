# ARTYMUS 3.0 — Access Doctrine

**Status:** Canonical access model  
**Version:** 1.0  
**Date:** May 2026

---

## Core Rule

```text
Public sees beauty.
Advisors see structure.
Operators see power.
```

ARTYMUS 3.0 is built around progressive revelation. The same system presents different levels of depth depending on who enters.

---

## Implementation Notes

- Tier state should be stored locally for continuity.
- The collector layer should never expose formulaic logic by default.
- The advisor layer may expose formulas, scores, confidence, and scenario framing.
- The operator layer may expose execution links and system documentation.
- Authentication must eventually replace phrase-based demo access for real deployments.
- Phrase-based access is acceptable only for prototype, demonstration, and ritualized presentation use.

---

## Canonical Summary

ARTYMUS 3.0 does not treat access as a login.

It treats access as a threshold.

The system reveals itself only to the level the viewer is meant to hold.
